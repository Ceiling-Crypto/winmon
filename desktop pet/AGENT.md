# 桌宠 Agent / 动作包 / 全屏漫游（设计稿）

> 状态：**部分实现**。工作区内的短距离二维漫游已经进了
> `winmon_pet.py`；音乐/视频反应、动作包、Agent 仍是设计。
> 这份文档先把“像活的”拆成可验证的层，避免把 API、动画、系统监控和人格混成一团。
> 实现顺序见最后一节。

## 1. 三条边界

1. **Agent 只控制桌宠自己的表现**：说话、气泡、走动、看向、睡觉、吐泡泡。
   **不**通过桌宠去关窗口、结束进程、改系统设置；那些仍走 WinMon 原有的、
   有回读核对的控制路径。这样"人格怎么说"和"工具能做什么"不会混在一起。
2. **不隐藏人设**：用户选了 AI 人设，说什么、选哪个动作由模型理解决定；
   WinMon 只约束**动作词表**和预算，不替模型改写台词（除非用户自己写规则）。
3. **没有 key / 预算不足 / 不在允许时段** → 自动退回本地行为，
   不弹错误、不偷偷调用模型。

## 2. 三层结构

```text
本地状态层 PetBrain
  输入：是否在放媒体、媒体标题/状态、前台窗口、键鼠闲置、时间
  输出：idle / walk / watch / sleep / bubble / hop
        ↓（本地规则，0 token）
动作层 PetActionPlayer
  输入：动作名 + 时长 + 方向
  输出：精灵帧 / 窗口位置 / 小气泡
        ↑（有直连且用户允许时才走）
Agent 层 PetAgent
  输入：人设 + 当前事实 + 允许的动作词表
  输出：严格 JSON {say, action, duration, mood}
```

### 2.1 本地状态层（先做，不花钱）

- **音乐**：`media_playing` 为真时，每 40–90 秒吐一个小泡泡（只有 `♪` 或歌名），
  不打断现有大信息气泡；切歌时冒一次。
- **视频/专注**：当前台窗口是视频/游戏（沿用现有识别，不新增抓屏）时，
  桌宠转到正面“认真看”；持续超过 N 分钟且键鼠闲置 → 躺平/睡觉。
- **没人理**：键鼠闲置超过 10 分钟，动作变慢、偶尔睡着；一动键鼠就醒。
- **全屏漫游（已实现基础版）**：不再只沿任务栏横着走；在**工作区**内选二维目标点，
  横走用侧面、向上用背面、向下用正面；碰到屏幕边/任务栏就停。
  拖拽仍然优先，拖到哪儿记哪儿。

这些行为**不调用模型**，保证没有 key 的用户也能看到“活的”桌宠。

### 2.2 动作包（开源素材“喂进去”）

不把某套 GIF 写死在代码里，而是读**动作包目录**：

```text
desktop pet/actions/<pack>/
├─ manifest.json
├─ front/001.png ...
├─ side/...
└─ sleep/...
```

```json
{
  "name": "community-whale-idle",
  "license": "MIT",
  "source": "https://github.com/...",
  "frame_size": [238, 238],
  "actions": {
    "idle":  {"frames": ["front/001.png", "front/002.png"], "fps": 6, "loop": true},
    "walk":  {"frames": ["side/001.png"], "fps": 8, "loop": true},
    "watch": {"frames": ["front/010.png"], "fps": 2, "loop": true},
    "sleep": {"frames": ["sleep/001.png"], "fps": 1, "loop": true},
    "bubble": {"frames": ["front/020.png"], "fps": 6, "loop": false}
  }
}
```

规则：
- **只认本地文件**，不在启动时联网下载；用户自己从 GitHub 下载后放进目录。
- `license` / `source` 必填，界面上显示；没有明确开源许可的包不加载。
- 缺某个动作就退回默认三视图，不因为一个包坏掉让桌宠消失。
- 动作包只提供**画面**，不提供可执行代码；`manifest.json` 不解析 Python。

第一版可以先不用外部包，把 `assets/` 当内置包；等 loader 稳定后再接社区动作。

### 2.3 Agent 层（人格由模型决定）

复用现有直连配置、预算账本和人设，不新建一套 key：

```text
系统提示：
  你是 <persona>。只输出一个 JSON：
  {"say": "不超过 50 字", "action": "idle|walk|watch|sleep|bubble|hop",
   "duration": 5, "mood": "..."}
  不能请求关窗/结束进程/运行命令；不知道就选 idle。
```

- 调用频率：默认 **2–5 分钟一次**，可在设置里关；受现有 `Budget` 限制。
- 只有用户显式开启「桌宠 Agent」且当前直连配置有效才调用。
- 返回非法 JSON / 动作不在词表 → 丢弃本次，保持本地状态（不惩罚、不重试狂刷）。
- 台词不经过 WinMon 的“改写”；只做长度/空值保护。用户接受“agent 的理解”，
  但**动作只能是桌宠动作**，这是安全边界。
- 桌宠的大信息气泡仍是只读事实；Agent 的小气泡是“它在说话”，两者分开，
  避免把模型的话伪装成系统读数。

## 3. 设置里会多什么

- 桌宠：全屏漫游（默认关？）、允许睡觉、允许吐泡泡、动作包选择。
- Agent：开关、频率、最大每日调用、使用哪个人设、当前直连对象（复用）。
- 预算不足 / 没 key 时显示“本地模式”，不反复弹提示。

## 4. 实现顺序（建议）

1. **A（不花钱）**：`PetBrain` + 全屏二维漫游 + 音乐泡泡 + 闲置睡觉；
   先用默认三视图，不动现有设置结构。
2. **B（动作包）**：manifest loader + 校验 + 设置里的包选择；
   只接 MIT/Apache 等明确许可的素材，保留 source/license。
3. **C（Agent）**：动作协议 + 预算 + 人设 + 频率限制；
   仍只允许桌宠动作，不开放系统控制。
4. **D（体验）**：把“认真看/躺平/吐泡泡”做成可关的细项，补回归测试和截图。

每一步都能单独回退；C 没做好时，A/B 仍然是一只完整的本地桌宠。
